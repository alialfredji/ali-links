# Astro Brand Starter

This is the control room for a reusable, bilingual Astro website. The starter is deliberately small: one homepage, two locales, static output, first-class images, strong discovery metadata, and documented extension seams.

<Callout id="guide-purpose" tone="info">
  Use the Design canvas to inspect responsive intent, the Prototype to switch between English and Swedish, and this guide to understand what to change, what not to couple, and how the system reaches production.
</Callout>

The redirect at the root route reads the browser language on the client. Swedish visitors enter at `/sv/`; everyone else enters at `/en/`. Every localized page still exposes a visible selector, canonical URL, and reciprocal hreflang links. English remains the deterministic fallback.

## Extension rules

<Callout id="extension-rule" tone="info">
  Add a new page when it has a distinct search intent or user task. Add a new component when a pattern repeats or owns behavior. Add a dependency only when native Astro and browser capabilities would make the implementation less clear or less reliable.
</Callout>

<Table
  id="extension-guide"

  rows={[
    ["A second content page", "Create mirrored en/sv routes and reuse BaseLayout", "Canonical and hreflang parity"],

    ["Analytics", "Add one consent-aware integration in BaseLayout", "No blocking script on the critical path"],
    ["Forms", "Use a host function or external endpoint behind a small form component", "Static pages remain deployable everywhere"],
