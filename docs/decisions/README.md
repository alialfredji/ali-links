# Decision Records

This directory contains architectural and technical decisions using the Agent Decision Record format.

## How to Add a Decision

1. Copy `000-template.md`.
2. Rename it to `NNN-short-description.md` using the next number.
3. Fill in every section.
4. Add it to the index.
5. Commit with `docs: add decision NNN — short description`.
